# 阿里云 MCP 多账号管理工具 - 用户指南

## 服务简介

阿里云 MCP 多账号管理工具是一个基于 FastMCP 的阿里云运维助手，支持多账号统一查询、资源盘点、监控分析、账单查看和操作审计。

所有工具均为只读调用，只会执行 Describe、List、Query、Lookup 等查询接口，不会修改任何资源。

## 快速开始

### 首次使用建议

新会话建议先让 Agent 调用：

```text
aliyun_bootstrap_session
```

它会一次返回：MCP 是否可用、账号是否加载成功、已接入产品清单和运行策略。若只想确认账号数量，可调用：

```text
aliyun_get_account_count
```

### 账号凭证读取规则

MCP 会按以下顺序读取账号凭证（从高到低）：

1. `.env` 中的 `ALIYUN_ACCOUNT_{KEY}_ACCESS_KEY_ID/ACCESS_KEY_SECRET/DEFAULT_REGION`
2. 显式 profile：`ALIYUN_ACCOUNT_{KEY}_CLI_PROFILE`
3. 自动回退 profile：先尝试账号 key（如 `staging`），再尝试 `default`

补充说明：

- 本地 profile 默认读取 `~/.aliyun/config.json`，也可通过 `ALIYUN_CLI_CONFIG_PATH` 指定路径。
- 当前仅支持读取 CLI `mode=AK` 的 profile。

### Landing Zone / Resource Directory 模式

项目账号很多时，推荐使用 RD 管理账号统一发现子账号，避免为每个账号配置 AK/SK。

基本思路：

1. 只配置一个 RD 管理账号（AK/SK 或 CLI profile）。
2. 每个子账号创建同名只读角色，例如 `ReadOnlyForMcp`。
3. 启用 `ALIYUN_RD_AUTO_DISCOVERY=true`。
4. MCP 自动发现子账号，并生成 `rd_{子账号ID}` 格式的账号标识。

示例问法：

```text
列出所有已配置账号。
查看 rd_1234567890123456 的资源概览。
查看 rd_1234567890123456 的 ECS 实例。
```

### 先确认有哪些账号

接入 MCP 客户端后，可以先让 Agent 调用：

```text
aliyun_list_configured_accounts
```

或直接用自然语言提问：

```text
有哪些已配置的阿里云账号？
介绍一下 production 账号。
staging 账号默认区域是什么？
```

### 基本使用方式

建议直接使用自然语言描述需求，并在问题中明确账号标识。

```text
production 账号有哪些 ECS 实例？
查看 staging 账号的 VPC 列表。
查看某个安全组的详细规则。
查看 production 账号有哪些 RDS 实例。
检查某个 CLB 的后端健康状态。
查看某个 CLB 的监听配置和后端服务器。
列出 production 账号的 OSS Bucket。
列出 production 账号的 ALB、NLB、EIP、NAT、ACK 集群和 SLS Project。
帮我看一下 2026-04 的账单总览。
查询最近 24 小时的告警历史。
最近谁修改过安全组？
```

### 避免命令审批弹窗

需要报表时，推荐让 Agent 直接生成 Markdown 表格，或调用 MCP 内置报表工具：

```text
把查询结果整理成 Markdown 表格。
需要当前时间时，调用 aliyun_get_current_time，不要使用 terminal/date。
把查询结果用 aliyun_generate_report_docx 生成 Word 文档，不要使用 terminal、python、pip、pandoc 或 write_file。
把查询结果用 aliyun_generate_report_pptx 生成 PPT 文档，不要使用 terminal、python、pip、pandoc 或 write_file。
把查询结果用 aliyun_generate_report_pdf 生成 PDF 文档，不要使用 terminal、python、pip、pandoc 或 write_file。
把查询结果用 aliyun_generate_report_html 生成 HTML 文档，不要使用 terminal、python 或 write_file。
把查询结果用 aliyun_generate_report_csv 生成 CSV 文本，不要使用 terminal、python -c 或 openpyxl。
```

说明：当前时间、Word/DOCX、PPT/PPTX、PDF、HTML 与 CSV 都应由 MCP 工具生成。本 MCP 不建议通过本地 terminal、date、execute_code、Python、pandoc、Excel 脚本或 write_file 生成文件，这类操作容易触发客户端的 Command Approval Required。

## 功能分类

### 当前主要缺口

以下产品已在能力矩阵中标记为“尚未接入”，bot 被问到时应调用 `aliyun_get_product_support_status` 明确说明限制，不要改用 terminal/API 脚本：

- RAM/访问控制：用户、角色、策略、MFA、AccessKey 清单。
- KMS：密钥、凭据与资源加密配置。
- WAF：域名接入、防护策略与攻击事件。
- CDN/DCDN：加速域名、回源、证书、流量与带宽。
- DNS/云解析：域名与解析记录。
- PolarDB：集群、备份、性能与连接信息。
- NAS：文件系统、挂载点、生命周期配置。
- CEN/TR：云企业网、转发路由器、网络实例连接与路由。
- 配置审计 Cloud Config：资源合规、规则评估与修正建议。
- 云安全中心 Security Center：漏洞、基线、告警、资产安全态势。
- ARMS/APM：应用监控、链路追踪、错误分析。
- DTS：迁移、同步与订阅任务状态。
- RocketMQ/Kafka/MNS：消息实例、Topic/Queue、Group、订阅与堆积状态。
- MSE/SAE/FC：微服务引擎、Serverless 应用、函数、触发器与部署状态。
- ACR/ASM：镜像仓库、镜像版本、扫描结果、服务网格实例与数据面配置。
- MaxCompute/DataWorks/Hologres/AnalyticDB/EMR/PAI：大数据、数仓、AI 工作空间、任务、集群与用量。
- TableStore/Lindorm/HBase：表格存储、宽表实例、索引与容量。
- DDoS/堡垒机：高防实例、防护事件、堡垒机资产授权与运维审计。
- VPN/高速通道/全球加速/PrivateLink：专线、VPN、终端节点、全球加速监听与健康状态。
- EventBridge/OOS/ROS：事件总线、运维编排、资源编排栈与执行事件。
- CloudSSO：目录、用户、访问配置与账号授权。
- Elasticsearch/OpenSearch：实例与集群详情。

### 8. ECS 快照与备份策略查询

适合梳理 ECS 云盘自动快照策略、策略绑定关系、实际快照记录，并输出备份策略 SOP。

常见问法：

```text
帮我梳理 GMI 当前的 ECS 备份策略。
查看 gmi_infra 账号 cn-shanghai 的自动快照策略。
哪些云盘没有绑定自动快照策略？
查看 d-xxxxxx 云盘最近的自动快照。
```

说明：

- `aliyun_describe_auto_snapshot_policies` 查询自动快照策略名称、保留天数、执行星期、执行时间点、跨地域复制等配置。
- `aliyun_describe_auto_snapshot_policy_associations` 查询策略与云盘的绑定关系。
- `aliyun_describe_disks` 查询云盘清单，并可过滤已绑定或未绑定自动快照策略的云盘。
- `aliyun_describe_snapshots` 查询实际快照记录，可按实例、云盘、快照类型过滤。
- `aliyun_lookup_events` 只作为补充审计证据，不再作为快照策略主数据来源。

对应工具：

- `aliyun_describe_auto_snapshot_policies`
- `aliyun_describe_auto_snapshot_policy_associations`
- `aliyun_describe_disks`
- `aliyun_describe_snapshots`
- `aliyun_lookup_events`

### 10.1 SSL 证书查询

适合检查 HTTPS 监听绑定证书、证书状态和到期信息。

常见问法：

```text
查看 production 账号有哪些 SSL 证书。
查看 production 账号有哪些 SSL v2 证书。
检查 production 账号证书是否快到期。
先查 alb-xxxxxx 的 HTTPS 监听，再查看监听绑定的证书详情。

```

说明：

- `aliyun_get_alb_listener_attribute` 用于查看 ALB HTTPS 监听绑定的 `CertificateId`。
- `aliyun_list_ssl_certificates` 用于查询 SSL/CAS v2 证书列表，返回 `CertificateList` 中的 `NotAfter` / `NotBefore` 等有效期字段。
- `aliyun_list_ssl_certificate_orders` 用于列出 SSL/CAS v1 证书订单和到期相关字段。
- `aliyun_describe_ssl_certificate_state` 用于按证书 ID 查询证书状态。
- 需要安装 `alibabacloud_cas20200407` 依赖，并给 RAM 只读权限添加 CAS/数字证书管理相关只读动作。

对应工具：

- `aliyun_get_alb_listener_attribute`
- `aliyun_list_ssl_certificates`
- `aliyun_list_ssl_certificate_orders`
- `aliyun_describe_ssl_certificate_state`

### 12. 云防火墙公网防护查询

适合查看云防火墙中互联网边界公网 IP 是否已添加防护，类似控制台“防火墙开关 / 互联网边界防火墙”里的“未受保护、已受保护”状态。

常见问法：

```text
查看 production 账号有哪些公网 IP 未添加云防火墙防护。
列出云防火墙互联网边界的未受保护公网资产。
统计 gmi_infra 账号已受保护和未受保护的公网 IP 数量。
查询 8.8.8.8 这个公网 IP 是否在云防火墙中开启保护。
```

说明：

- `aliyun_get_cloud_firewall_public_ip_protection_status` 会把公网 IP 按已受保护、未受保护、未知状态分组。
- `aliyun_describe_cloud_firewall_assets` 返回云防火墙资产列表原始信息，适合核对控制台字段。
- `aliyun_describe_cloud_firewall_traffic_log` 对应控制台“日志审计 > 流量日志”，可按 `src_ip`、`dst_ip`、`dst_port`、`direction` 查询访问源 IP。该接口仅支持 7 日内数据，建议单次查询不超过 1 天。
- `aliyun_describe_eip_addresses` 只能查 EIP 本身，不能完整判断是否已加入云防火墙防护。
- 需要安装 `alibabacloud_cloudfw20171207` 依赖，并给 RAM 只读权限添加 `yundun-cloudfirewall:DescribeAssetList`。

对应工具：

- `aliyun_get_cloud_firewall_public_ip_protection_status`
- `aliyun_describe_cloud_firewall_assets`
- `aliyun_describe_cloud_firewall_traffic_log`
- `aliyun_describe_eip_addresses`

### 13. ACK、OSS 与 SLS 查询

适合做容器平台、对象存储和日志平台的基础盘点。

常见问法：

```text
列出 production 账号的 ACK 集群。
列出 production 账号的 OSS Bucket。
查看某个 Bucket 的基础信息。
列出 production 账号的 SLS Project。
列出某个 Project 下的 Logstore。
```

说明：

- ACK 当前先提供集群列表查询。
- OSS 当前提供 Bucket 列表与 Bucket 基本信息。
- SLS 当前提供 Project、Logstore 列表和 GetLogs 日志查询。访问日志、流量日志、云防火墙日志需要先在对应产品中开启投递到 SLS，并确认 Project/Logstore 名称。

对应工具：

- `aliyun_describe_ack_clusters`
- `aliyun_list_oss_buckets`
- `aliyun_get_oss_bucket_info`
- `aliyun_list_sls_projects`
- `aliyun_list_sls_logstores`
- `aliyun_query_sls_logs`

### 13.1 SLS 访问日志与流量日志查询

适合查询云防火墙日志审计或已经投递到 SLS 的访问日志、CLB/ALB 日志等，用于回答“谁访问了某个端口”“源访问 IP 是什么”。

常见问法：

```text
列出 production 账号的 SLS Project，再列出可疑 Project 下的 Logstore。
查询 gmi_security 账号某个 Logstore 中最近 24 小时访问 3389 的源 IP。
在云防火墙流量日志里按 src_ip 统计访问 47.117.89.160:3389 的次数。
通过云防火墙日志审计查询最近 1 小时访问 47.117.89.160 目的端口 3389 的源 IP。
```

说明：

- 云防火墙控制台“日志审计 > 流量日志”优先使用 `aliyun_describe_cloud_firewall_traffic_log`。
- `aliyun_query_sls_logs` 是通用 SLS GetLogs 查询工具，不负责自动开启日志投递。
- `from_time` / `to_time` 支持 Unix 秒、Unix 毫秒或 ISO8601，例如 `2026-05-22T00:00:00Z`。
- 查询字段名取决于具体 Logstore 索引，常见可能是 `src_ip`、`dst_ip`、`dst_port`、`source_ip`、`destination_port` 等。
- 示例查询语句：`dst_ip:47.117.89.160 and dst_port:3389 | select src_ip, count(1) as cnt group by src_ip order by cnt desc limit 20`。

对应工具：

- `aliyun_describe_cloud_firewall_traffic_log`
- `aliyun_list_sls_projects`
- `aliyun_list_sls_logstores`
- `aliyun_query_sls_logs`

### 14. 操作审计与变更追踪

适合追查最近的配置变更、人工操作和审计事件。

常见问法：

```text
最近谁修改过 ECS 或安全组？
查询 production 账号最近 24 小时的 ActionTrail 事件。
帮我筛选 ServiceName=Ecs 的操作记录。
```

说明：

- `aliyun_lookup_events` 支持按时间范围和条件过滤。
- `start_time`、`end_time` 建议使用 ISO8601 UTC，例如 `2026-05-01T00:00:00Z`。

对应工具：

- `aliyun_lookup_events`

## 使用技巧

### 1. 始终先说清楚账号

推荐：

```text
production 账号的 ECS 实例
staging 账号最近 24 小时的告警
```

不推荐：

```text
帮我看看 ECS
查一下告警
```

### 2. 复杂任务分两步走

例如排障时，先识别账号和资源，再查看监控或审计信息：

```text
先介绍一下 production 账号。
再查看 production 账号最近 24 小时的告警。
最后查询最近相关的 ActionTrail 事件。
```

### 3. 时间范围尽量明确

下面两类说法更容易得到稳定结果：

```text
最近 24 小时
2026-05-01 到 2026-05-07
```

### 4. 标签查询要给出键值

例如：

```text
查询 env=prod 的资源
查询 project=wukong 的标签资源
```

## 常见问题

### Q: 我修改了 `.env` 里的账号配置，必须重启 MCP 吗？

A: 不一定。可以直接调用 `aliyun_reload_account_configs` 重新加载账号配置和客户端缓存。

### Q: 我不知道支持哪些账号，怎么办？

A: 先问“有哪些已配置账号”，或直接调用 `aliyun_list_configured_accounts`。

### Q: 查询时一定要带账号吗？

A: 建议始终带上。这个项目的设计目标就是避免串账号查询。

### Q: 没有在 `.env` 里写 AK/SK，会自动读取本地阿里云 profile 吗？

A: 会。未设置 `ALIYUN_ACCOUNT_{KEY}_CLI_PROFILE` 时，会自动尝试 `${KEY}` 和 `default` 两个 profile。若你希望固定使用某个 profile，建议显式配置 `ALIYUN_ACCOUNT_{KEY}_CLI_PROFILE`。

### Q: 这个 MCP 会修改我的阿里云资源吗？

A: 不会。当前所有工具都是只读接口。

### Q: 为什么标签查询没有结果？

A: 先确认资源本身有标签，并确保提供了 `tags` 或 `resource_arns` 参数。

### Q: 怎么接入 Cursor 或 Claude Desktop？

A: 参考同目录下的 `REGISTRATION_GUIDE.md`。
