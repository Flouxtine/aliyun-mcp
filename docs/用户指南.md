# 阿里云 MCP 多账号管理工具 - 用户指南

## 服务简介

阿里云 MCP 多账号管理工具是一个基于 FastMCP 的阿里云运维助手，支持多账号统一查询、资源盘点、监控分析、账单查看和操作审计。

所有工具均为只读调用，只会执行 Describe、List、Query、Lookup 等查询接口，不会修改任何资源。

## 快速开始

### 账号凭证读取规则

MCP 会按以下顺序读取账号凭证（从高到低）：

1. `.env` 中的 `ALIYUN_ACCOUNT_{KEY}_ACCESS_KEY_ID/ACCESS_KEY_SECRET/DEFAULT_REGION`
2. 显式 profile：`ALIYUN_ACCOUNT_{KEY}_CLI_PROFILE`
3. 自动回退 profile：先尝试账号 key（如 `staging`），再尝试 `default`

补充说明：

- 本地 profile 默认读取 `~/.aliyun/config.json`，也可通过 `ALIYUN_CLI_CONFIG_PATH` 指定路径。
- 当前仅支持读取 CLI `mode=AK` 的 profile。

### 先确认有哪些账号

接入 MCP 客户端后，可以先让 Agent 调用：

```text
aliyun_list_configured_accounts
```

或直接用自然语言提问：

```text
有哪些已配置的阿里云账号？
介绍一下 production 账号。
staging 账号默认区域是什么？
```

### 基本使用方式

建议直接使用自然语言描述需求，并在问题中明确账号标识。

```text
production 账号有哪些 ECS 实例？
查看 staging 账号的 VPC 列表。
查看某个安全组的详细规则。
查看 production 账号有哪些 RDS 实例。
检查某个 CLB 的后端健康状态。
查看某个 CLB 的监听配置和后端服务器。
列出 production 账号的 OSS Bucket。
列出 production 账号的 ALB、NLB、EIP、NAT、ACK 集群和 SLS Project。
帮我看一下 2026-04 的账单总览。
查询最近 24 小时的告警历史。
最近谁修改过安全组？
```

## 功能分类

查看 lb-xxxxxx 的监听列表。
列出 production 账号的 Redis/Tair 实例。
列出 production 账号的 MongoDB 实例。
列出 production 账号的 ALB 和监听。
列出 production 账号的 NLB 和监听。

### 2. 标签与资源归属查询

适合按标签做资源筛选、归属核对和简单盘点。

常见问法：

```text
查询 production 账号中带 env=prod 标签的资源。
查看这些 ARN 对应的标签资源。
先列出支持标签查询的资源类型，再帮我筛选资源。
```

说明：

- `aliyun_list_tag_resources` 需要至少提供 `tags` 或 `resource_arns` 其中之一。
- `tags` 需要传 JSON 数组字符串，例如 `[{"Key":"env","Value":"prod"}]`。

对应工具：

- `aliyun_list_tag_resources`

### 3. 成本与账单分析

适合按账期查看账单总览，做月度对账或粗粒度成本分析。

常见问法：

```text
查看 production 账号 2026-04 的账单总览。
分析一下这个月 ECS 相关费用。
按产品看一下 2026-04 的账单分布。
```

说明：

- `billing_cycle` 格式为 `YYYY-MM`，例如 `2026-04`。
- 当前提供的是账单总览，不是明细级别的逐资源成本拆分。

对应工具：

- `aliyun_query_bill_overview`

### 4. 监控与告警分析

适合查看最近一段时间的云监控告警历史。

常见问法：

```text
查询 production 账号最近 24 小时的告警历史。
查看 ECS CPU 相关告警。
筛选某条告警规则的历史告警记录。
```

说明：

- `start_time` 和 `end_time` 使用 Unix 毫秒时间戳字符串。
- 可结合 `namespace`、`metric_name`、`rule_id`、`rule_name` 做过滤。

对应工具：

- `aliyun_describe_alert_history_list`

### 5. RDS 连接与数据库排障

适合先确认 RDS 的实例状态、网络属性与基础连接信息。

常见问法：

```text
列出 production 账号的 RDS 实例。
查看 rm-xxxxxx 的实例详情。
这个 RDS 是不是在 VPC 网络里？
帮我排查为什么应用连不上这个 RDS。
```

说明：

- `aliyun_describe_rds_instances` 适合先做筛选和盘点。
- `aliyun_describe_rds_instance_attribute` 适合查看单实例的详细连接与状态信息。

对应工具：

- `aliyun_describe_rds_instances`
- `aliyun_describe_rds_instance_attribute`
- `aliyun_lookup_events`

### 6. Redis 与 MongoDB 查询

适合对缓存和文档数据库做实例盘点、网络确认和基础只读排查。

常见问法：

```text
列出 production 账号的 Redis/Tair 实例。
查看 r-bpxxxxxx 的 Redis 实例详情。
列出 production 账号的 MongoDB 实例。
查看 dds-bpxxxxxx 的 MongoDB 实例详情。
```

说明：

- Redis/Tair 走 `aliyun_describe_redis_instances` 与 `aliyun_describe_redis_instance_attribute`。
- MongoDB 走 `aliyun_describe_mongodb_instances` 与 `aliyun_describe_mongodb_instance_attribute`。

对应工具：

- `aliyun_describe_redis_instances`
- `aliyun_describe_redis_instance_attribute`
- `aliyun_describe_mongodb_instances`
- `aliyun_describe_mongodb_instance_attribute`

### 7. 网络与安全组排障

适合检查 ECS 关联的安全组和具体入出方向规则。

常见问法：

```text
列出 production 账号 cn-hangzhou 的安全组。
查看 sg-xxxxxx 的详细规则。
检查这个安全组是否放通了 22 端口。
先查实例绑定了哪些安全组，再分析 SSH 为什么不通。
```

说明：

- `aliyun_describe_instances` 已支持通过 `security_group_id` 反查实例。
- `aliyun_describe_security_group_attribute` 可按 `ingress`、`egress` 或 `all` 查询规则。

对应工具：

- `aliyun_describe_security_groups`
- `aliyun_describe_security_group_attribute`
- `aliyun_describe_instances`

### 8. SLB/CLB 与后端健康排障

适合排查 502、后端不健康、监听异常等入口层问题。

常见问法：

```text
列出 production 账号的 CLB。
查看 lb-xxxxxx 的详情和后端服务器。
查看 lb-xxxxxx 的监听配置。
查看 lb-xxxxxx 的后端健康状态。
检查 443 监听的后端是否健康。
帮我排查这个 CLB 为什么出现 502。
```

说明：

- `aliyun_describe_load_balancers` 用于查看 CLB 实例和按后端 ECS 过滤。
- `aliyun_describe_load_balancer_attribute` 用于查看单个 CLB 的详细配置与后端服务器。
- `aliyun_describe_load_balancer_listeners` 用于查看监听列表、端口和协议。
- `aliyun_describe_slb_health_status` 用于查看指定监听或全量监听的健康状态。

对应工具：

- `aliyun_describe_load_balancers`
- `aliyun_describe_load_balancer_attribute`
- `aliyun_describe_load_balancer_listeners`
- `aliyun_describe_slb_health_status`
- `aliyun_lookup_events`

## 使用技巧

### 1. 始终先说清楚账号

推荐：

```text
production 账号的 ECS 实例
staging 账号最近 24 小时的告警
```

不推荐：

```text
帮我看看 ECS
查一下告警
```

### 2. 复杂任务分两步走

例如排障时，先识别账号和资源，再查看监控或审计信息：

```text
先介绍一下 production 账号。
再查看 production 账号最近 24 小时的告警。
最后查询最近相关的 ActionTrail 事件。
```

### 3. 时间范围尽量明确

下面两类说法更容易得到稳定结果：

```text
最近 24 小时
2026-05-01 到 2026-05-07
```

### 4. 标签查询要给出键值

例如：

```text
查询 env=prod 的资源
查询 project=wukong 的标签资源
```

## 常见问题

### Q: 我修改了 `.env` 里的账号配置，必须重启 MCP 吗？

A: 不一定。可以直接调用 `aliyun_reload_account_configs` 重新加载账号配置和客户端缓存。

### Q: 我不知道支持哪些账号，怎么办？

A: 先问“有哪些已配置账号”，或直接调用 `aliyun_list_configured_accounts`。

### Q: 查询时一定要带账号吗？

A: 建议始终带上。这个项目的设计目标就是避免串账号查询。

### Q: 没有在 `.env` 里写 AK/SK，会自动读取本地阿里云 profile 吗？

A: 会。未设置 `ALIYUN_ACCOUNT_{KEY}_CLI_PROFILE` 时，会自动尝试 `${KEY}` 和 `default` 两个 profile。若你希望固定使用某个 profile，建议显式配置 `ALIYUN_ACCOUNT_{KEY}_CLI_PROFILE`。

### Q: 这个 MCP 会修改我的阿里云资源吗？

A: 不会。当前所有工具都是只读接口。

### Q: 为什么标签查询没有结果？

A: 先确认资源本身有标签，并确保提供了 `tags` 或 `resource_arns` 参数。

### Q: 怎么接入 Cursor 或 Claude Desktop？

A: 参考同目录下的 `REGISTRATION_GUIDE.md`。
